# Аудит действий в интерфейсе

| Действие | Когда используется | Решение в 1.3.0 |
|---|---|---|
| Добавить протоколы | Начало каждой работы | Один выбор нескольких файлов. Стрелка открывает выбор папки, также поддерживается перетаскивание. Проверка запускается автоматически. |
| Проверить | После чтения книги | Убрано как отдельное действие. Результат виден в строке протокола. |
| Исправить / Открыть | При замечании или по желанию посмотреть средства | Одно прокручиваемое окно. Оно показывает общие недостающие сведения, весь список средств и сгруппированные замечания по приборам. Вкладки, отдельные карточки для ввода и отдельная кнопка подтверждения партии убраны. |
| Сохранить изменения | Когда сотрудник дополняет факты | Одно сохранение общих полей и всех отредактированных приборов. Сведения из Excel применяются сразу. |
| Подтвердить карточки и повторить поиск | Только при неоднозначности или сбое | Подтверждение находится возле сравниваемых карточек, повтор поиска сохраняет экран и введённые значения. Однозначная действующая карточка применяется автоматически. |
| Уточнить знаки отдельного прибора | Редкое исключение из общего правила Excel | Флажок открывает поля на том же экране. Для обычной партии поля не показываются. |
| Следующий прибор | При отсутствии индивидуальных данных у нескольких СИ | Переключает прибор на том же экране с сохранением черновика. |
| Убрать из списка | Если книгу выбрали по ошибке | Доступно в окне протокола. Исходная книга остаётся на диске. |
| Просмотреть и открыть карточку | Перед выгрузкой, по необходимости | Четыре основные колонки. Карточка открывается только по запросу. Статус показывает, готова ли запись к выгрузке. |
| Сформировать XML | Когда есть готовые записи | Одно нажатие с известной папкой. Подтверждение состава остаётся при исключении записей или повторной выгрузке. |
| Открыть папку / Просмотреть файл | После выгрузки | На итоговом экране видны число записей и полный путь. XML показывается в читаемом виде. |
| Настройки лаборатории и папки | При настройке рабочего места и изменениях | Один раз задаются реквизиты и папка. Правило срока задаётся по документу и ограничивается типом и периодом. |
| Справочник, связь, журнал, история, XML | При уточнении, проверке и повторном открытии | Доступны через настройки. Технический просмотр XML включается отдельно. |
