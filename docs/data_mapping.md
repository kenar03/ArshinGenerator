# Карта полей RTD v1

Шаблон и заполненная книга имеют одинаковый набор из восьми листов. Версия распознаётся по сигнатурам листов «Таблицы», «Данные», «Отчёт», «Эталоны» и «Оборудование». Книга читается из одного снимка байтов. Формулы, связи и VBA при чтении не исполняются.

| Поле личного кабинета | Элемент XML | Источник и преобразование | Обязательность и действие при отсутствии |
|---|---|---|---|
| Тип СИ в реестре ФИФ ОЕИ | `miInfo/singleMI/mitypeNumber` | Таблицы!L27. Отчёт!A22 и Таблицы!I19 повторяют реквизит. Официальное название из точной записи MIT видно в предпросмотре. | В XML обязателен номер. При пропуске уточняется источник Excel. |
| Модификация СИ | `miInfo/singleMI/modification` | Обязательный тип из Таблицы!A27 и заполненные исполнение B27 и взрывозащита C27. Полная маркировка из Отчёт!A61 хранится для прослеживаемости. | Длина D27 и другие параметры полной маркировки в XML не входят. Буквы исполнения сохраняются. У ТСП-0193 для исполнения `17М/РЭД` или `17M/РЭД` действует прежнее правило об опускании заказного обозначения `/РЭД`. Другие значимые части исполнения сохраняются. |
| Заводской номер | `miInfo/singleMI/manufactureNum` | Таблицы!D2:G4, I2, B19. Сверка диапазонов и списка с числом J27 и Данные!B2:G1001. Читаются нули и код. | Требуется идентификатор каждой единицы. Расхождение или дубли блокируют запись. |
| Год выпуска и альтернативное обозначение | `manufactureYear`, `inventoryNum` | Отдельного поля года выпуска в книге нет. При первичной поверке предлагается год из Таблицы!B24. Доступен ручной ввод для партии и отдельных приборов. Код из Данные!E является частью заводского номера. | Год необязателен. Альтернативный идентификатор поверяемого СИ в этом модуле не используется. |
| Иные категории поверяемого СИ | `crtmitypeTitle`, `milmitypeTitle`, `miInfo/etaMI` | В снимках видны альтернативные поля. RTD-шаблон фиксирует обычный утверждённый тип. | Альтернативные ветви схемы, источника для них в RTD нет. |
| Условный шифр знака поверки | `signCipher` | В Excel отдельного поля нет. Источник — настройки лаборатории или ранее сохранённый реквизит протокола. | Обязательны 1–3 заглавные русские буквы. Исходное значение для новой базы — `ВЦЯ`. |
| Владелец | `miOwner` | Отчёт!J24. Заголовок в A18 обозначает исполнителя, колонка J24 содержит владельца. | Обязателен по применяемой XSD 2020. |
| Дата поверки | `vrfDate` | Таблицы!B24, сохранённая дата Excel. Отчёт!A52 повторяет дату. | Обязательна. При пропуске или неверном значении исправляется источник. |
| Вид поверки | `type` | Таблицы!B1, повтор в Отчёт!A20. Значения из Списки!K4:K5 переводятся в `1` или `2`. | При пустом значении или неизвестном виде поверки выгрузка блокируется. |
| Срок поверки СИ | `validDate` | Дата из Таблицы!B24 и МПИ в полных годах из Таблицы!K27. Таблицы!J30 и Эталоны!G относятся к эталону. | Модуль ТСП/ТСМ рассчитывает последний день перед годовщиной. Недействительные исходные значения блокируют экспорт. Для непригодного СИ дата в XML опускается. |
| Использование результатов калибровки | `calibration` | В Excel отдельного поля нет. | Обязательно. Берётся из настроек лаборатории или ранее сохранённого реквизита того же протокола. Исходное значение для новой базы — «Нет». |
| Документ на методику | `docTitle` | Отчёт!A33, с нормализацией пробелов. Заголовок из A32 и методика из MIT не используются как значение. | Обязателен. Его можно сверить в карточке прибора. |
| Поверитель | `metrologist` | Таблицы!B23, повтор в Отчёт!A51. Приведение к формату «Фамилия И.О.». | Заполняется по ТЗ. При отсутствующем или неоднозначном ФИО требуется уточнение. |
| Заключение и причина непригодности | `applicable` либо `inapplicable/reasons` | Таблицы!C19, F20 и заключение в отчёте. В старом формате это Отчёт!A45, в новом опорном шаблоне — A336. Статус каждого ЧЭ из Данные!I сверяется с допуском в Таблицы!H:J. Точки определяются по классу в Таблицы!G27. Для C нужна строка 0 °C, для AA, A и B — обе строки. | Одна запись на физическое СИ. Отказ одного ЧЭ означает непригодность СИ. Расхождение статуса, допуска или заключения блокирует выгрузку. |
| Наклейка | `applicable/stickerNum` | Таблицы!B20, повтор в Отчёт!H48. Один указанный номер относится к одному СИ. В партии нужна привязка к конкретному прибору. | По XSD 2020 необязателен. Если указан, передаётся строка до 128 символов. |
| Знаки в паспорте и на приборе | `applicable/signPass`, `applicable/signMi` | Таблицы!B22 и B21, повтор в Отчёт!H50 и H49. `V` означает «да», прочерк означает «нет». | Обязательны при пригодности. Применяются ко всей партии, индивидуальное исключение уточняется отдельно. |
| Свидетельство и извещение поверяемого СИ | — | На снимке есть поля. Номера на листах «Эталоны» и «R-T» принадлежат средствам поверки. | В ветвях результата пакетного импорта отдельных тегов для этих номеров нет. |
| СИ-эталоны и обычные средства поверки | `means/mieta/number`, `means/mis/mi/typeNum` с `manufactureNum` или `inventoryNum` | В новом формате заголовок «Используется» в Оборудование!F1 определяет выбор из F2:F301. В старом формате Таблицы!A10:A18 связываются с Оборудование!E. Реквизиты берутся из Оборудование!A:D. | Требуется хотя бы одно отмеченное средство. Проверяются точные официальные реквизиты, пригодность и срок поверки. При неоднозначности нужно уточнить Excel. |
| Первичные эталоны, эталоны единиц, СО, вещества, метод без средств | `means/npe`, `uve`, `ses`, `reagent`, `oMethod` | Альтернативы ручного интерфейса. В контрольной книге выбраны обычные СИ и СИ-эталоны. | При наличии подтверждённого основания `npe` и `uve` поддерживаются справочником. Для остальных ветвей источник RTD не установлен. |
| Температура, давление, влажность | `conditions/temperature`, `pressure`, `hymidity` | Таблицы!B5:B7, повторы Отчёт!L28:L30. Единицы °C, кПа и %, десятичная запятая. | Обязательны. При пропуске уточняются фактические условия. |
| Другие факторы | `conditions/other` | Таблицы!B8, повтор Отчёт!L31. Числовое напряжение с единицей В. | Необязательно. |
| Состав СИ, сокращённый объём, прочие сведения | `structure`, `brief_procedure/characteristics`, `additional_info` | Отдельных достоверных полей в книге нет. Адрес проведения, параметры расчётов и типовой текст отчёта не переносятся в эти поля. | Необязательны. |
| Номер и вложение протокола | `protocol/content` для вложения, отдельного тега номера нет | Таблицы!D1, Отчёт!A20/A54. Номер используется в истории. | Вложение необязательно. XLSM не относится к допустимым типам вложения. |
| Сведения о публикации | — | Статус возникает в личном кабинете после загрузки. Отчёт!A46 содержит типовую фразу шаблона. | В XML импорта такого поля нет. |

Проверены все восемь листов. «Списки» задаёт значения для выпадающих полей. «R to T» и «R-T» хранят коэффициенты и расчётные таблицы, включая документы эталонов. «Данные» хранит заводские номера, индексы ЧЭ и результаты. Из этих вспомогательных листов в XML уходят только однозначно сопоставленные сведения. На снимках другая запись, поэтому её год, наклейка, сроки, владелец, условия и перечень средств не переносятся в контрольный протокол.

В контрольной книге кириллическая «Р» для АСПТ указана в Оборудование!A7, а сохранённая строка в Таблицы!A15 содержит латинскую `P`. Книга читается, а строка требует согласования реквизитов в Excel. При запросе MIETA отправляется точный номер из реквизитов выбранного оборудования.

«Журнал0» (скрытый) и «Журнал1» имеют разные колонки. В «Журнал1» G — маркировка, H — количество, J — заводские номера, K — протокол, L — общий результат, N — примечание. В данных встречаются длинные партии, составные номера, пропуски в диапазонах, смешение алфавитов и дефекты отдельных СИ при положительном результате строки. Журнал использован для выбора тест-кейсов.

Расчётные строки `Данные!2:1001` и `Таблицы!35:2034` покрывают 1000 блоков. Для XML проверяются все заявленные блоки, сохранённые измерения и список номеров. В новом отчёте сведения об итогах и приложение ищутся по заголовкам. В опорной книге результаты находятся в A335, заключение в A336, приложение в A345, полное обозначение в A352 и заголовки измерений в A353.
