# Карта полей RTD v1

Шаблон и заполненная книга имеют одинаковый набор из восьми листов. Версия распознаётся по сигнатурам листов «Таблицы», «Данные», «Отчёт», «Эталоны» и «Оборудование». Книга читается из одного снимка байтов. Формулы, связи и VBA при чтении не исполняются.

| Поле | Источник и преобразование | XML | Достоверность |
|---|---|---|---|
| Протокол | Таблицы!D1, кэш формулы `_ProtocolFileStem` при последнем сохранении | В схеме нет отдельного номера. Прослеживаемость в карточке и истории. Дополнительный текст переносится по явному вводу. | Подтверждена координата |
| Заводской номер | Таблицы!B19, кэш списка из D2:G4 и I2, сверка с Данные!G2:G1001 и количеством J27. В G объединены текст F с сохранёнными нулями и код E. Однозначные визуальные замены кириллицы в латиницу с проверкой дублей | miInfo/singleMI/manufactureNum | Подтверждён источник. Расхождение требует проверки |

| Полная маркировка и модификация | Отчёт!A61 и Таблицы!A27:D27. Кандидат из структурированных модели, исполнения и Ex, без длины. Для неизвестных исполнений используется подтверждённое соответствие по типу и полной маркировке | miInfo/singleMI/modification | ТСП/ТСМ кириллицей. Написание остальных частей и состав модификации сверяются по описанию типа |

«Журнал0» (скрытый) и «Журнал1» имеют разные колонки. В «Журнал1» G — маркировка, H — количество, J — заводские номера, K — протокол, L — общий результат, N — примечание. В данных встречаются длинные партии, составные номера, пропуски в диапазонах, смешение алфавитов и дефекты отдельных СИ при положительном результате строки. Журнал использован для выбора тест-кейсов.

SHA-256 неизменяемых книг: шаблон `3ca95e1e2f1970432c1c8740653986a1cfd0df2b70f1623ce09a63e746f27846`, пример `285e26e26a9bbfb6d99aae55a748850358d69830f6a58578c7214116a91de57d`, журнал `1d54029520fb7fb83b5ad6c6bbb5a083c5649522c28f151087aafa71c22bf785d`.
