# Карта полей RTD v1

Шаблон и заполненная книга имеют одинаковый набор из восьми листов. Версия распознаётся по сигнатурам листов «Таблицы», «Данные», «Отчёт», «Эталоны» и «Оборудование». Книга читается из одного снимка байтов. Формулы, связи и VBA при чтении не исполняются.

| Поле личного кабинета | Элемент XML | Источник и преобразование | Обязательность и действие при отсутствии |
|---|---|---|---|
| Сведения о СИ, утверждённый тип | `miInfo/singleMI/mitypeNumber` | Таблицы!L27. Отчёт!A22 и Таблицы!I19 повторяют реквизит. Официальное название из точной записи MIT видно в предпросмотре. | В XML обязателен номер. При пропуске уточняется источник Excel. |
| Модификация СИ | `miInfo/singleMI/modification` | Обязательный тип из Таблицы!A27 и заполненные исполнение B27 и взрывозащита C27. Полная маркировка из Отчёт!A61 хранится для прослеживаемости. | Длина D27 и другие параметры полной маркировки в XML не входят. Буквы исполнения сохраняются. У ТСП-0193 для исполнения `17М/РЭД` или `17M/РЭД` действует прежнее правило об опускании заказного обозначения `/РЭД`. Другие значимые части исполнения сохраняются. |

| Дата поверки | `vrfDate` | Таблицы!B24, сохранённая дата Excel. Отчёт!A52 повторяет дату. | Обязательна. При пропуске или неверном значении исправляется источник. |
| Вид поверки | `type` | Таблицы!B1, повтор в Отчёт!A20. Значения из Списки!K4:K5 переводятся в `1` или `2`. | При пустом значении или неизвестном виде поверки выгрузка блокируется. |
| Срок поверки СИ | `validDate` | Дата из Таблицы!B24 и МПИ в полных годах из Таблицы!K27. Таблицы!J30 и Эталоны!G относятся к эталону. | Модуль ТСП/ТСМ рассчитывает последний день перед годовщиной. Недействительные исходные значения блокируют экспорт. Для непригодного СИ дата в XML опускается. |

| Поверитель | `metrologist` | Таблицы!B23, повтор в Отчёт!A51. Приведение к формату «Фамилия И.О.». | Заполняется по ТЗ. При отсутствующем или неоднозначном ФИО требуется уточнение. |
| Заключение и причина непригодности | `applicable` либо `inapplicable/reasons` | Таблицы!C19, F20 и Отчёт!A45. Статус каждого ЧЭ из Данные!I сверяется с допуском в Таблицы!H:J в двух точках. Индексы определяются по Данные!B:C и схеме в Таблицы!H27. | Одна запись на физическое СИ. Отказ одного ЧЭ означает непригодность СИ. Расхождение статуса, допуска или заключения блокирует выгрузку. |

| Свидетельство и извещение поверяемого СИ | — | На снимке есть поля. Номера на листах «Эталоны» и «R-T» принадлежат средствам поверки. | В ветвях результата пакетного импорта отдельных тегов для этих номеров нет. |
| СИ-эталоны и обычные средства поверки | `means/mieta/number`, `means/mis/mi/typeNum` с `manufactureNum` или `inventoryNum` | Таблицы!A10:A18 связываются с Оборудование!E. В контрольной книге выбраны обычные СИ и СИ-эталоны. | При наличии подтверждённого основания `npe` и `uve` поддерживаются справочником. Для остальных ветвей источник RTD не установлен. |
| Температура, давление, влажность | `conditions/temperature`, `pressure`, `hymidity` | Таблицы!B5:B7, повторы Отчёт!L28:L30. Единицы °C, кПа и %, десятичная запятая. | Обязательны. При пропуске уточняются фактические условия. |
| Другие факторы | `conditions/other` | Таблицы!B8, повтор Отчёт!L31. Числовое напряжение с единицей В. | Необязательно. |

| Сведения о публикации | — | Статус возникает в личном кабинете после загрузки. Отчёт!A46 содержит типовую фразу шаблона. | В XML импорта такого поля нет. |

Проверены все восемь листов. «Списки» задаёт значения для выпадающих полей. «R to T» и «R-T» хранят коэффициенты и расчётные таблицы, включая документы эталонов. «Данные» хранит заводские номера, индексы ЧЭ и результаты. Из этих вспомогательных листов в XML уходят только однозначно сопоставленные сведения. На снимках другая запись, поэтому её год, наклейка, сроки, владелец, условия и перечень средств не переносятся в контрольный протокол.

В контрольной книге кириллическая «Р» для АСПТ уже указана в Оборудование!A7. Сохранённая копия строки в Таблицы!A15 всё ещё содержит латинскую `P`. Если значения совпадают во всём остальном и строка справочника единственная, эта разница учитывается только для поиска строки. В MIETA отправляется неизменённое значение A7.

«Журнал0» (скрытый) и «Журнал1» имеют разные колонки. В «Журнал1» G — маркировка, H — количество, J — заводские номера, K — протокол, L — общий результат, N — примечание. В данных встречаются длинные партии, составные номера, пропуски в диапазонах, смешение алфавитов и дефекты отдельных СИ при положительном результате строки. Журнал использован для выбора тест-кейсов.

В текущем шаблоне и двух книгах `Данные!K1:L2` содержит печатную вместимость 62 блока / 31 СИ с двумя ЧЭ. Расчётные строки `Данные!2:1001` и `Таблицы!35:2034` покрывают 1000 блоков. В `Отчёт` есть ссылки на блок 63 и следующие. Проверка 62 показывает предупреждение о печати. Для XML проверяются все заявленные блоки, их кэшированные измерения и соответствие списку номеров. Проверен отдельный сценарий с полностью заполненным блоком 63.
