СИ-Экспорт
Краткая инструкция

Программа берёт готовые протоколы поверки из Excel и создаёт файлы:
• PDF — отчёт, который можно открыть или распечатать.
• XML — файл для загрузки результатов поверки в «Аршин».

1. Нажмите «Добавить протоколы» и выберите сохранённые файлы Excel.

2. Для отчёта нажмите «Создать PDF». Если программа попросит,
   выберите папку. Когда файлы будут готовы, нажмите «Открыть папку».
   Для создания PDF на компьютере должен быть установлен Microsoft Excel.

3. Для загрузки в «Аршин» дождитесь конца проверки и нажмите
   «Сформировать XML». Выберите, где сохранить файл, если программа
   попросит. Готовый файл загрузите в «Аршин» вручную.

Если проверка закончилась, а кнопка «Сформировать XML» недоступна,
выберите протокол с замечаниями и нажмите «Просмотреть».
В открывшемся окне указано, что нужно проверить или исправить.
После исправления сохраните протокол в Excel и нажмите «Перепроверить».
