## Контрольный протокол

- Из П-Т1-з2-1260-26 прочитаны 25 физических СИ, номера от `009W6` до `033W6`, модификация ТСМ-0193-01, владелец, поверитель, дата 22.11.2026, методика и условия. Для всех приборов согласованы заключение и результаты измерений. Для всей партии знак в паспорте есть, знак на приборе отсутствует.
- Публичный поиск проверил восемь средств поверки. Семь действуют на дату протокола. Поверка ИВТМ-7М-Д № 85789 закончилась 16.11.2026. Состояние видно в списке оборудования с обеими карточками ПТСВ-1-2, обеими карточками ЭЛЕМЕР и подтверждённой АСПТ.
- В контрольной книге отсутствуют номера наклеек, вид поверки, шифр, признак калибровки и готовая дата окончания. Программа показывает их как препятствия или уточнения. Общие реквизиты можно сохранить один раз. Срок вычисляется только по настроенному правилу с основанием. Контрольная книга открывалась для чтения, её SHA-256 совпал с исходным.
- При коэффициентах Qt 1,25 и 1,50 с Windows-бэкендом проверены главное окно, экран исправления и предварительный просмотр. Поиск из интерфейса показал фактическое состояние «7 из 8 проверено».

## Тесты и проверочные XML

35 автоматических тестов. Включены полный путь синтетической партии, согласованные и противоречивые измерения, два ЧЭ, повторное использование подтверждений, наложение реквизитов лаборатории только на пустые поля, правило срока, индивидуальное исключение знака, групповой откат SQLite при ошибке, повторное чтение XML и локальная XSD-валидация.

В папке `release\Проверочные XML 1.3.0` два файла из 25 синтетических записей. Файл со стикерами проходит XSD 2022. Файл без наклеек проходит оригинал 2020 и получает 25 ошибок по XSD 2022. Для обоих повторно проверены число и состав записей, номера СИ, наклейки, знаки и оборудование.

Из публичной справки «Аршина» скачана XSD пакетной загрузки 2022. Контрольная сумма совпала со схемой сборки. Файлы проверены локально. Приём кабинетом версии 2020 и пакета без наклеек остаётся неподтверждённым. [Сравнение и официальные источники](schema_discrepancies.md).

## Проверка сборок

- Portable запущена из опубликованного ZIP без внешнего Python. После переноса в папку с кириллицей SQLite и выбранная папка восстановились.
- Установщик 1.3.0 собран. Установка и удаление проверены на сборке с тем же содержимым и отдельным идентификатором Inno Setup, поскольку на компьютере уже есть рабочие ярлыки. SHA-256 установленного приложения совпал с исполняемым файлом дистрибутива. Появились оба тестовых ярлыка, после удаления они исчезли, а SQLite осталась. Контрольные суммы рабочих ярлыков совпали.
- Из Portable и установленного тестового экземпляра MIT, MIETA и VRI ответили HTTP 200. Обе сборки прочитали 25 результатов контрольного протокола с неизменившейся контрольной суммой.
