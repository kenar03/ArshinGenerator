# Проверка версии 1.0.1

Сборки Windows x64 созданы на Windows 11 (10.0.22631) с Python 3.12.14, PySide6 Essentials 6.8.3, PyInstaller 6.13.0 и Inno Setup 6.7.3. Файлы не имеют подписи Authenticode. Windows 10 от 1809 входит в целевой диапазон Qt, отдельная проверка на Windows 10 в текущей среде не проводилась. ## Выполнено

- 18 автоматических тестов. Проверены номера и их алфавиты, профили маркировки, ФИО, точность и сроки сопоставления оборудования, два ЧЭ, неполные и отрицательные результаты, дубли, пакет с несколькими протоколами, разбиение по байтам, XSD, повторное чтение с диска и откат при ошибке аудита. Проверены просмотр, фильтрация и контраст выделения при подмене исходной палитры Qt.
- В Windows просмотрены выбранная строка таблицы, выпадающий список, выделенный текст формы, диалог выбора файлов, предупреждение и просмотрщик XML.
- Обе сборки запустились с обычным Windows-бэкендом Qt, при PATH из системных каталогов и заведомо отсутствующих внешних путях Python. В каждой образец дал 25 карточек. Статус готовности определяется обычными проверками и отсутствующими подтверждениями.
- Portable запущена из распакованного ZIP. После перемещения в другой каталог с кириллицей и пробелами сохранились SQLite и последняя выбранная папка.
- Установщик проверен временной установкой в текущем профиле. Созданы ярлык в меню «Пуск», выбранный ярлык на рабочем столе и запись удаления в HKCU. Запуск приложения сохранил данные в отдельной пользовательской папке, повторный запуск прочитал настройки. После удаления исчезли приложение, ярлыки и запись HKCU. База осталась на месте.
- SHA-256 шаблона, заполненного протокола и журнала совпали с хешами до чтения. Отправки в личный кабинет не было.
- Публичный поиск приложения вернул одну точную карточку из общедоступной выдачи Росстандарта. Реквизиты учебного протокола для запроса не использовались.

Готовый XML проверен на синтетических сценариях.
