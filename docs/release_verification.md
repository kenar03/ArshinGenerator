## Изменённые файлы

- `ui/protocol_list.py`, `ui/main.py`, `ui/common.py` добавляют отметки по пути протокола и общую галочку с частичным состоянием. Отметки управляют удалением. Двойное нажатие открывает сведения, XML включает всю проверенную партию.
- `ui/main.py` убирает запрос подтверждения при повторной генерации. История и аудит SQLite, блокировка дубликатов в партии, подтверждение перезаписи Windows, XSD и разбиение пакетов продолжают работать.

Сеть используется при импорте подходящих протоколов, при необходимой актуализации перед экспортом и при явной повторной проверке.
- `assets/app.png` хранит исходный PNG, `assets/app.ico` содержит семь размеров. `__main__.py`, `ui/common.py`, `ui/dialogs.py`, `ui/protocols.py`, `ui/main.py`, `build.ps1` и `packaging/arshin.iss` подключают значок к окнам Qt, двум EXE, ярлыкам, записи приложений Windows и идентификатору группировки панели задач. Идентификатор установки сохранён. - `__init__.py` и `packaging/arshin.iss` задают версию. `tests/test_ui.py`, `tests/test_workflow.py` и `packaging/test-release.ps1` покрывают изменения. `README.md` и `docs/quick_start.md` описывают рабочий процесс.
