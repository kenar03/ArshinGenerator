# Схема пакетного импорта

Приложена пользователем из раздела «Справочная информация» портала в ноябре 2026 г. `import.2022-12-21.xsd`, SHA-256 `71843c9544546ce2a319f14f8fd645c6d18c080ad73007070815e2a33e2c5911`. Пространство имён `urn://fgis-arshin.gost.ru/module-verifications/import/2020-06-19`. Версия схемы и пространство имён имеют разные даты.

| Поле / правило | Руководство v.2.2.4 и снимки | Требование XSD / решение |
|---|---|---|
| `miOwner` | Стр. 97, 1..1 | 0..1, длина 1–512 при наличии |
| `applicable/stickerNum` | Стр. 97, 0..1, строка(128); на снимке пусто | 1..1, ровно 11 цифр ASCII. Положительная запись без номера блокируется |
| `signCipher` | Стр. 97, строка(32) | 1–3 заглавные буквы А–Я |
| `manufactureYear` | Целое число в таблице | `xsd:gYear`. В этом приложении четырёхзначный год |
| `metrologist` | Стр. 97, 0..1 | XSD совпадает. ТЗ требует заполнение и формат Фамилия И.О. |
| `means` | Стр. 46, требуется хотя бы одно поле; метод без средств исключает средства. Стр. 97–99, раздел обязателен | В XSD минимум одна дочерняя ветвь. Для RTD нужен подтверждённый набор средств |
| Свидетельство / извещение | Отдельные видимые поля в ручной форме | В `applicable` и `inapplicable` соответствующих тегов нет |
| Положительная/отрицательная дата окончания | Стр. 97 описывает случаи пропуска при только первичной поверке и непригодности | 0..1. Дата берётся по основанию. При непригодности программа её опускает |
| Размер / обработка | Пп. 3.4.1.11–3.4.1.11.1, PDF 56–57: 5 МБ и целиком отклоняемый файл при ошибке XSD | Проверка UTF-8 по байтам с запасом, проверка всего пакета и повторное чтение с диска |

Приложенный `arshin_export_example.xml` содержит два `result` в правильном namespace. lxml обнаружил пропуск `stickerNum` в обеих записях и пустой `means` во второй. Строки `TechnometerCRMID` говорят о предполагаемом происхождении выгрузки из TechnometerCRM, статус приёма неизвестен. Образцы PDF на стр. 100–108 иллюстрируют ветви единственного СИ, СИ в качестве эталона и разные средства поверки. Они содержат текстовые заполнители, включая «Номер наклейки», и не являются тестовыми файлами для XSD. П. 3.4.7 описывает токены личного кабинета для передачи. Проверка местной схемы не устанавливает правила приёма портала.
