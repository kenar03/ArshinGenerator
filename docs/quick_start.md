# Аршин · Генератор XML

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `ArshinGenerator.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `ArshinGenerator-Setup-x64.exe`. Приложение доступно через меню «Пуск». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Стрелка рядом с кнопкой открывает выбор папки. Книги также можно перетащить из Проводника.
2. Дождитесь автоматической проверки. Если есть замечания, нажмите **«Исправить»** в строке протокола. На одном экране показаны сведения, которые нужно дополнить, и весь список средств поверки. Для эталона с несколькими подходящими карточками отметьте фактически использованные поверочные схемы и нажмите **«Подтвердить»**.
3. Нажмите **«Просмотреть»**, чтобы увидеть заводские номера, модификации, даты и заключения. Изменения нужны только для записей с замечаниями. Признаки знаков для всей партии берутся из Excel. На экране «Исправить» можно задать исключение для конкретного прибора.
4. Нажмите **«Сформировать XML»**. Программа сохранит пакет в папку **Документы → Аршин** или в папку, выбранную в настройках. В итоговом окне видны количество записей и путь к файлу. Кнопка **«Открыть папку»** ведёт к готовому пакету. Уполномоченный сотрудник загружает его в личный кабинет вручную.

Если готовы только некоторые результаты, перед сохранением программа покажет, какие записи исключаются, и запросит подтверждение состава пакета.

В **«Настройки → Реквизиты лаборатории»** можно один раз задать свой шифр знака, использование калибровки и вид поверки для пустого поля Excel. В **«Правила срока поверки»** добавляются правила, подтверждённые документами по типу СИ. Программа рассчитывает дату по заданному правилу, если совпадают тип, дата поверки и МПИ, а калибровка не использовалась.

Для пригодного СИ опубликованная схема пакетной загрузки требует фактический номер наклейки из 11 цифр. Одного номера для партии недостаточно. Параметры ручного заполнения портала могут отличаться.

В меню **«Настройки»** также доступны справочник, история, просмотр сохранённого XML, проверка связи и журнал. Исходный код XML открывается в **«Техническом режиме»**.

Для восстановления базы закройте приложение, сохраните копию текущей базы и положите резервный файл в папку данных под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
