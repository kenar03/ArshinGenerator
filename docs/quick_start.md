# Аршин · Генератор XML

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `ArshinGenerator.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `ArshinGenerator-Setup-x64.exe`. Приложение доступно через меню «Пуск». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Стрелка рядом с кнопкой открывает выбор папки. Книги также можно перетащить из Проводника.
2. Дождитесь автоматической проверки Excel и реестров. Чтобы увидеть замечания, дважды нажмите на строку или нажмите **«Просмотреть»**. Если нужно исправить данные в Excel, сохраните книгу и добавьте её повторно. Среди нескольких подходящих карточек эталона отметьте использованные записи и нажмите **«Выбрать запись»**.
3. В сведениях протокола можно просмотреть тип СИ, модификацию, методику, заводские номера, результаты, сроки и средства поверки. Чтобы убрать протоколы из списка, выделите их и нажмите **«Удалить выбранные»** или Delete. Книги сохранятся на диске.
4. Когда готовы все протоколы, нажмите **«Сформировать XML»** и укажите имя и папку в окне Windows. Для большого пакета достаточно выбрать папку, а номера частей программа назначит сама. Подтверждение сохранения появится в главном окне. Уполномоченный сотрудник загружает полученный XML в кабинет вручную.

Если хотя бы одна запись требует исправления, кнопка «Сформировать XML» недоступна. При повторной выгрузке программа предупредит о возможных дубликатах.

В **«Настройки → Реквизиты лаборатории»** можно один раз задать шифр знака, использование калибровки и вид поверки для пустого поля Excel. В **«Служебных инструментах»** можно настроить правила сроков по документам или указать документ и срок для исключения по конкретному протоколу. Для применимого правила программа берёт последний календарный день перед годовщиной по МПИ.

Номер наклейки необязателен. Если в Excel указан один номер для партии, уточните, какому прибору он принадлежит. Владелец и методика обязательны. Если методики нет, заполните строку «Методика поверки» на листе «Отчёт», сохраните книгу и добавьте протокол заново.

В **«Служебных инструментах»** доступны история, резервная копия, просмотр сохранённого XML и диагностика подключения. Программа формирует XML по XSD от 19.06.2020.

Для восстановления базы закройте приложение, сохраните копию текущей базы и положите резервный файл в папку данных под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
