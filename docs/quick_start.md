# Аршин · Генератор XML

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `ArshinGenerator.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `ArshinGenerator-Setup-x64.exe`. Приложение доступно через меню «Пуск». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Стрелка рядом с кнопкой открывает выбор папки. Книги также можно перетащить из Проводника.
2. Дождитесь автоматической проверки. Если у протокола есть замечания, нажмите **«Исправить»** в его строке. Окно покажет средства поверки и сведения, которые требуют внимания. Для эталона отметьте карточки всех фактически использованных поверочных схем и нажмите **«Подтвердить»**.
3. Нажмите **«Просмотреть результаты»** и при необходимости откройте карточку прибора. Согласованные заключение и измерения завершённого протокола дают автоматический итог. Общие сведения можно сохранить сразу для партии. Для пригодного СИ пакетная XSD требует фактический номер наклейки из 11 цифр.
4. Когда обязательные замечания устранены, нажмите **«Сформировать XML»** и выберите папку. В итоговом окне указаны количество результатов и путь к файлу. Оттуда можно открыть папку или просмотреть файл. Уполномоченный сотрудник загружает его в личный кабинет вручную.

Если готовы только некоторые результаты, перед сохранением программа покажет, какие записи исключаются, и запросит подтверждение состава пакета.

В меню **«Настройки»** доступны справочник, история, просмотр ранее сохранённого XML, проверка подключения к ФИФ ОЕИ и диагностический журнал. Встроенный просмотрщик показывает сведения по-русски. Исходный код XML открывается в **«Техническом режиме»**.

Для восстановления базы закройте приложение, сохраните копию текущей базы и положите резервный файл в папку данных под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
