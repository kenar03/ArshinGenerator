# Аршин · Генератор XML

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `ArshinGenerator.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `ArshinGenerator-Setup-x64.exe`. Приложение доступно через меню «Пуск». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Можно выбрать папку или перетащить книги из Проводника.
2. Дождитесь автоматической проверки. Во вкладке **«Протоколы»** разберите общие замечания. Для неоднозначного оборудования откройте **«Проверить оборудование протокола»** и выберите подтверждённую карточку.
3. Проверьте вкладку **«Приборы»**. Для завершённого протокола с согласованным заключением и измерениями итог подставляется из Excel. Уточните только показанные исключения и недостающие реквизиты. Для пригодности пакетная XSD требует фактический номер наклейки из 11 цифр.
4. Нажмите **«Сформировать XML»** и выберите папку. Подтверждение состава требуется для неполного или повторного пакета. Просмотрщик откроет сформированные и проверенные файлы. Уполномоченный сотрудник переносит их в личный кабинет вручную.

В меню **«Дополнительно»** доступны справочник, история, просмотр ранее сохранённого XML и диагностический журнал. Для восстановления базы закройте приложение, сохраните копию текущей базы и положите резервный файл в папку данных под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
