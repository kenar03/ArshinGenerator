# Аршин · Генератор XML

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `ArshinGenerator.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `ArshinGenerator-Setup-x64.exe`. Приложение доступно через меню «Пуск». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Можно выбрать папку или перетащить книги из Проводника.
2. Нажмите **«Проверить данные»**. Выберите строку с замечаниями и откройте **«Уточнить сведения протокола»**. При отсутствии сохранённых вычислений проверьте завершённость книги в Excel, сохраните и загрузите снова.
3. Модификацию подтвердите по официальному описанию типа. Средства сверяйте по конкретной карточке в **«Справочнике ФИФ ОЕИ»**. В подтверждении укажите идентификатор, даты оборудования и основание.
4. Откройте **«Предварительный просмотр»**. В карточке СИ подтверждаются итоговое заключение и индивидуальные реквизиты. Сверьте **«Поля будущего XML»** для готовой записи.
5. Нажмите **«Сформировать XML»**, подтвердите состав пакета и выберите папку. Просмотрщик откроет сформированные и проверенные файлы. Уполномоченный сотрудник переносит их в личный кабинет вручную.

В **«Истории XML»** можно повторно открыть файлы, зафиксировать фактический статус обработки и создать резервную копию. Для восстановления закройте приложение, сохраните копию текущей базы и положите резервный файл в **«Папку данных»** под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
