# СИ-Экспорт

## Запуск на Windows 10/11 x64

- **Portable**. Распакуйте ZIP в папку, доступную для записи, и запустите `SI-Export.exe`. Для переноса закройте программу и скопируйте всю папку, включая `data` и `portable.flag`.
- **Установщик**. Запустите `SI-Export-Setup-x64.exe`. Приложение доступно через меню «Пуск» под именем «СИ-Экспорт». Ярлык рабочего стола выбирается при установке. Данные хранятся в `%LOCALAPPDATA%\ArshinGenerator` и сохраняются при удалении программы.

Для обновления закройте приложение. Запустите новый установщик поверх установленной версии. Для Portable распакуйте свежий архив в отдельную папку и скопируйте в неё папку `data` из предыдущего выпуска.

## Подготовка пакета

1. Нажмите **«Добавить протоколы»** и выберите сохранённые книги. Стрелка рядом с кнопкой открывает выбор папки. Книги также можно перетащить из Проводника.
2. Дождитесь автоматической проверки Excel и реестров. Тип протокола и состояние показаны в списке. Чтобы увидеть замечания, дважды нажмите на строку или нажмите **«Просмотреть»**. В разделе **«Что нужно исправить»** указаны замечания и адреса ячеек. Кнопка **«Открыть в Excel»** открывает исходную книгу. После исправления сохраните её и нажмите **«Перепроверить»** в главном окне. Программа перечитает все добавленные книги и сохранит выделение и галочки.
3. В просмотре протокола видны сведения о СИ, поверке, условиях и средствах поверки. Нажмите **«Показать все»**, чтобы раскрыть таблицу с заводскими номерами, годом выпуска и результатом каждого прибора. Чтобы убрать протоколы из главного списка, отметьте их галочками и нажмите **«Удалить выбранные»** или Delete. Галочка в заголовке отмечает все строки.
4. Когда готовы все протоколы, нажмите **«Сформировать XML»**. При ручном сохранении укажите имя и папку в окне Windows. Для большого пакета достаточно выбрать папку, а номера частей программа назначит сама. Фактический путь появится в главном окне. Уполномоченный сотрудник загружает полученный XML в кабинет ФГИС «Аршин» вручную.

XML включает все загруженные протоколы. Если хотя бы одна запись требует исправления, кнопка «Сформировать XML» недоступна. Когда требуется только обновление сведений ФИФ ОЕИ, та же кнопка запускает проверку и продолжает сохранение после успешной сверки. При сбое связи проверьте подключение и повторите формирование или нажмите «Перепроверить».

В новом шаблоне отметьте используемые средства поверки знаком `+` в столбце «Используется» листа «Оборудование». Старые книги используют перечень `Таблицы!A10:A18`. Для класса C проверяются сохранённые данные при 0 °C. Для AA, A и B проверяются обе точки.

Сверки ФИФ ОЕИ действуют 24 часа и сохраняются между запусками. Для внеплановой сетевой сверки нажмите **«Принудительно обновить данные ФИФ ОЕИ»** в настройках. В правом нижнем углу главного окна показаны число протоколов, физических приборов и готовых результатов.

В **«Настройках»** задаются условный шифр знака поверки и использование результатов калибровки. По умолчанию используются `ВЦЯ` и «Нет». Тип поверки берётся из ячейки B1 листа «Таблицы». Для ТСП/ТСМ программа рассчитывает срок по дате и МПИ из B24 и K27. При двух ЧЭ проверяются оба измерения и формируется одна запись на прибор.

Для первичной поверки исходный год выпуска берётся из даты поверки в B24. Для периодической поверки исходное значение пустое. В окне протокола можно выбрать всю партию или конкретный заводской номер, указать четыре цифры и нажать **«Сохранить год»**. Чтобы исключить год из XML для выбранных приборов, сохраните пустое поле.

Номер наклейки необязателен. Если указан один номер на всю партию, исходные сведения должны однозначно связывать его с прибором. Программа формирует XML по XSD от 19.06.2020.

## Сохранение XML

- **Каждый раз выбирать место сохранения** — режим по умолчанию. Программа запоминает последнюю папку, выбранную вручную.
- **Автоматически сохранять в папку** — включите режим в «Настройках» и выберите постоянную папку через «Обзор…». При совпадении имён программа добавит числовой суффикс. Если папка недоступна, можно выбрать другую для текущего сохранения. Постоянная папка берётся из настроек при следующей выгрузке.

## Служебный запуск

Закройте рабочее окно и выполните нужную команду из каталога приложения в PowerShell.

```powershell
.\SI-Export.exe --history
.\SI-Export.exe --view-xml "C:\Поверки\пакет.xml"
.\SI-Export.exe --check-connection "C:\Поверки\связь.json"
```

Окно истории позволяет открыть сформированный пакет и сохранить резервную копию. Проверка связи пишет отчёт JSON и журнал рядом с ним. Журнал приложения `diagnostics.log` хранится рядом с базой.

Для восстановления базы закройте приложение, сохраните копию текущей базы и положите резервный файл в папку данных под именем `arshin.sqlite3`. Папки с ранее сформированными XML переносятся отдельно.
